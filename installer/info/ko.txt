이 설치 프로그램이 하는 일

이 설치 프로그램에는 앱이 들어 있지 않습니다. github.com/danielcarli/lionorganizer 에 게시된 최신 버전을 내려받아 모든 파일을 검증합니다.

 1. 최신 릴리스를 찾아 파일 목록을 검증합니다(SHA-256).
 2. LionOrganizer(1MB 미만)를 내려받아 SHA-256을 검증합니다.
 3. Electron의 GitHub 릴리스에서 공식 Electron 런타임(약 110MB)을 내려받아 Electron이 게시한 체크섬으로 검증합니다.
 4. 앱을 구성하여 사용자 폴더에 설치합니다.

모든 파일은 HTTPS로 내려받습니다. 관리자 권한은 필요하지 않습니다. 검증이 하나라도 실패하면 아무것도 설치되지 않으며 기존 설치는 그대로 유지됩니다.

요구 사항

 - Windows 10(버전 1809 이상) 또는 Windows 11, 64비트(x64 또는 ARM)
 - 설치 중 인터넷 연결(약 110MB 다운로드)
 - 연결 속도에 따라 약 1분

업데이트
