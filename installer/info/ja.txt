このインストーラーの動作

このインストーラーにはアプリ本体は含まれていません。github.com/danielcarli/lionorganizer で公開されている最新バージョンをダウンロードし、すべてのファイルを検証します。

 1. 最新リリースを探し、そのファイル一覧を検証します（SHA-256）。
 2. LionOrganizer（1 MB 未満）をダウンロードし、SHA-256 を検証します。
 3. Electron の GitHub リリースから公式の Electron ランタイム（約 110 MB）をダウンロードし、Electron が公開しているチェックサムで検証します。
 4. アプリを組み立て、ユーザーフォルダーにインストールします。

すべて HTTPS でダウンロードされます。管理者権限は不要です。検証に一つでも失敗した場合は何もインストールされず、既存のインストールはそのまま残ります。

動作環境

 - Windows 10（バージョン 1809 以降）または Windows 11、64 ビット（x64 または ARM）
 - インストール中のインターネット接続（約 110 MB のダウンロード）
 - 回線速度にもよりますが、約 1 分

更新

スタートメニューの「LionOrganizer を更新」ショートカットを使うか、このインストーラーをもう一度実行してください。GitHub から最新バージョンを取得し直します。設定とカタログは保持されます。
