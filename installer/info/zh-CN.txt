本安装程序会做什么

本安装程序不包含应用本身。它会下载 github.com/danielcarli/lionorganizer 上发布的最新版本，并校验每个文件：

 1. 查找最新发布版本，并校验其文件列表（SHA-256）；
 2. 下载 LionOrganizer（不到 1 MB）并校验其 SHA-256；
 3. 从 Electron 的 GitHub 发布页下载官方 Electron 运行时（约 110 MB），并用 Electron 公布的校验和进行校验；
 4. 组装应用并安装到你的用户文件夹。

所有内容均通过 HTTPS 下载，无需管理员权限。任何一项校验失败都不会安装任何内容，已有的安装保持不变。

系统要求

 - Windows 10（1809 或更高版本）或 Windows 11，64 位（x64 或 ARM）；
 - 安装期间需要联网（约 110 MB 下载）；
 - 大约一分钟，视网络情况而定。

更新

使用“开始”菜单中的“更新 LionOrganizer”快捷方式，或再次运行本安装程序。它会重新从 GitHub 获取最新版本；你的设置和目录会被保留。
